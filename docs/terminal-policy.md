# Terminal policy

Ghostty is the sole supported terminal. It owns tabs and splits; Herdr owns persistent workspaces and agent visibility. Ghostty keeps the `Ctrl+b` prefix for tab and split actions; Herdr uses a live, user-only `F12` prefix override, not a repository-managed mapping. The owner verified delivery of F12 to Herdr, not all nested actions. See [shortcuts](shortcuts.md) for the configured mappings and [Herdr setup](herdr-setup.md#shortcut-ownership) for the live override and recovery.

Neither tmux nor Kitty is required or offered by the [deployment script](deploy-config.md). `config/tmux/.tmux.conf` and `config/kitty/` remain archival imports, not supported activation sources. Do not source the tmux file for inspection: it invokes TPM. tmux's default `Ctrl+b` prefix would compete with Ghostty's bindings if run inside it; this policy does not promise tmux pass-through. Neovim's `Ctrl+b` completion-scroll can also be intercepted by Ghostty. This policy favors familiar Ghostty controls; if nested use needs raw `Ctrl+b`, test an explicit pass-through or alternate key policy before changing bindings. No nested delivery was verified here.

For the archival Kitty configuration, `kitty.conf` includes `./theme.conf` first, then `current-theme.conf` near its end. Later settings may override earlier theme values; the exact effective theme needs a Kitty runtime check. `kitty.conf.bak` is a historical backup, not a second authoritative config. The imported config forces Wayland and `/bin/bash --login`; it is not the selected terminal or a supported macOS setup. Moving to Bash is separate work: do not activate or modify the imported `config/bash/.bashrc`, which has unsafe assumptions documented in [deployment limits](deploy-config.md).

Ghostty configuration is linked only after inspecting active paths and overrides for the target system. The script does not activate files without approval. Confirm tabs, split navigation/creation/close/zoom, Herdr F12, and Neovim key delivery interactively on the target before claiming end-to-end behavior. A syntax check alone cannot establish key delivery or session recovery.
