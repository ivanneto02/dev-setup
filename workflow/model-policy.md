# ChatGPT-plan model policy (bounded trial)

**Only route:** Pi's `openai` provider with a ChatGPT-plan OAuth credential. An OAuth request may use a provider API endpoint; that does not make it an API-key-billed request. OpenAI API keys are **never** allowed, even as a fallback. No paid extra usage or separately billed budget is approved. Local inference is a different route and is not approved by this policy. Do not switch to `openai-codex`, a proxy, another provider, or a different model without a new owner decision. If the approved route fails, stop; do not try a second credential.

| Role | Explicit Pi route | Thinking | Escalation |
| --- | --- | --- | --- |
| Interactive coordinator | `openai/gpt-6-sol` | medium | Use high only for a specific reasoning failure after checking plan availability; otherwise stop and ask. |
| Bounded implementation worker | `openai/gpt-6-sol` | medium | Use high on a new bounded attempt only after a specific failure and route recheck. |
| Independent reviewer | `openai/gpt-6-sol` | high | Report unresolved findings; do not automatically escalate the model or route. |

This reuses the model from the documented disposable trial, not a claim that it is the cheapest or best for every task. Do not save these choices as global Pi defaults. Before each launch, confirm the owner still permits this model on the signed-in plan **without paid extra usage**; if entitlement or billing cannot be confirmed, do not launch. Authentication alone cannot prove that condition. Select the route explicitly for the interactive coordinator (`pi --provider openai --model gpt-6-sol --thinking medium`) and for each Limen job (`--engine pi --provider openai --model gpt-6-sol --thinking medium`, or `high` for review). Do not rely on Limen's default `openai-codex/gpt-6-astra:high`, the saved Pi default, or a parent job's route. Check the actual launch arguments and auth again on continuations.

## Preflight and stop rules

Run `pi auth check --provider openai --model gpt-6-sol --json --no-refresh` and inspect **only** `status`, `provider`, and `authType`: require `ready`, `openai`, and `oauth`. Never use `--credentials`, `print-api-key`, or `print-bearer-token`; never log credentials or copy Pi's user-level `auth.json` into Git. If the check fails, expires, or reports a different type, stop; a separate interactive sign-in decision is needed. Check that no `--api-key` was passed, `OPENAI_API_KEY` is unset in the launching environment, and no custom `models.json` provider override/proxy redirects `openai`. If any check is uncertain, stop. These checks are a human preflight, **not** a fail-closed enforcement mechanism: Pi's credential precedence puts runtime `--api-key` above stored OAuth. `LIMEN_PREFLIGHT=auth` adds a Pi auth readiness check when set, but Limen does not inspect the credential type or billing. A `ready` result and a previous trial do not verify plan entitlement or prevent paid extra usage. Keep credentials in Pi's private user store outside this repository; never set an API key for this workflow.

Delegate only when independent work improves the result. Start at most **one** worker or reviewer at a time; wait and inspect its work before another. For detached spawns, use `LIMEN_MAX_TOOL_CALLS=50 LIMEN_PREFLIGHT=auth limen spawn ... --timeout 10m --detached`. Require explicit flags above. Do not use hosted `--tab` for a bounded trial: it has no outer timeout or tool-call cap. Do not start `limen continue` as an unbounded substitute: its help has no `--timeout`; inspect its limits before any continuation. Stop on auth or entitlement uncertainty, rate limiting, repeated failure, or unexpected costs. Do not switch to paid usage, increase the limits, or retry on a different provider. Ten minutes, 50 tool calls, and one-at-a-time are execution rules, **not** a token limit, hard concurrency guard, or spending cap; Pi's catalog cost display is an estimate, not a billing guarantee.

Installed Limen revision `3419a4ca62eb3de413e30fc3c417952ff3c20847` exposes explicit spawn route/thinking/timeout flags, optional `LIMEN_PREFLIGHT=auth`, and `LIMEN_MAX_TOOL_CALLS` in its local runtime. Pi's installed `docs/models.md` describes credential precedence and `docs/providers.md` describes the private store. Neither the metadata check nor this documentation verifies current plan billing, paid-extra controls, or account entitlement. Recheck versions and the plan before relying on this policy on another host. Reconsider model choice only after representative tasks show a reliable lower-resource OAuth model on the same approved plan; do not infer price from catalog estimates alone.
